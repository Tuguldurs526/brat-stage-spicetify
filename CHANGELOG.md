# Changelog

## 4.0.0 — responsive controls and true word timing

- Live per-track YouTube URL activation after paste, text input debounce, or Enter
- Best-effort YouTube captions control plus video caption mask / video panel crop
- Hide future lyrics before their first timestamp and during explicitly timed gaps
- Compact artwork/song metadata in the dock by default; optional left or hidden
- Raised, responsive dock in windowed Spotify; lower on real fullscreen
- 32 deterministic contrasting cinematic palette pairs with variable line cadence
- Album-derived colors now choose a text color with minimum 4.5:1 contrast
- Playback progress interpolation, tested word timestamp reveal
- Exact word timestamps preferred; inaccurate estimated words now explicitly opt-in
- Optional Better Lyrics API key support for uncached tracks
- Added unit tests, browser regression scripts, responsive and word timing smoke tests
- Fixed a null video time crash that occurred before YouTube reported playback progress
